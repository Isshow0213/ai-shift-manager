# AI Shift Manager

## 概要

AI Shift Manager は、アルバイトのシフト希望提出と店長のシフト作成を効率化するためのWebアプリです。

従業員はシフト希望を提出し、管理者は必要人数を設定した上で、自動生成されたシフトを確認できます。

## 解決したい課題

現在、シフト希望はLINEなどで個別に送られることが多く、店長は提出状況の確認やシフト作成に多くの時間を使っています。

このアプリでは、シフト希望の回収とシフト作成をWeb上で一元管理することで、店長の負担を減らすことを目指します。

## 現在実装済みの機能

- 店舗所属の権限に応じたログイン後の画面分岐
- カスタムUserモデル
- シフト希望提出
- 提出済みシフト希望一覧
- 必要人数設定（単日・平日／祝前日／休日ごとの一括登録・編集）
- 確定シフト保存
- 簡易シフト自動生成
- 店舗ごとのシフトカレンダー、手動追加・編集・削除
- 店舗全員の月間シフト表（勤務時間・勤務日数・日別出勤人数）
- 店長による招待リンク発行と、招待先店舗への従業員登録

## ローカルで画面を見る

```sh
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python manage.py migrate
.venv/bin/python manage.py runserver
```

`http://127.0.0.1:8000/login/` からログインします。有効な `StoreMembership` の権限が `manager` なら管理者ダッシュボード、それ以外なら従業員の希望カレンダーを開きます。

店長は画面上部の「従業員画面へ」から自分のシフト希望・確定シフト画面を開けます。従業員画面には、店長だけに「管理画面へ」ボタンが表示されます。

## 従業員を招待する

1. 店長が「従業員管理」を開き、「招待リンクを発行する」を押します。
2. 発行されたURLをコピーし、従業員に送ります。
3. 従業員がURLを開き、苗字・名前・メールアドレス・パスワードと確認用パスワードを入力します。
4. 新しいUserと、その招待の店舗にひもづく有効なstaffのStoreMembershipを作成し、希望カレンダーを開きます。

招待は7日間有効で、1つのリンクから1人を登録できます。未使用のリンクは店長が無効化できます。従業員登録後のログインにはメールアドレスを使えます。既存アカウントのユーザー名によるログインも引き続き使えます。

従業員追加は招待による本人登録を使用します。店長は「従業員管理」の所属一覧でランクA・B・Cを選び、従業員ごとの「保存」を押して変更できます。ランクは店舗ごとの所属に保存します。既存の所属・権限はDjango Adminで管理できます。新規所属の初期値はstaff、ランクC、希望勤務回数0回／週です。

発行URLは開いている環境のホスト名を使います。従業員へ共有する際は、従業員がアクセスできる環境で発行してください。

認証とパスワードの検証は [Djangoの認証](https://docs.djangoproject.com/en/6.0/topics/auth/customizing/) と [パスワード管理](https://docs.djangoproject.com/en/6.0/topics/auth/passwords/) の機能を使用しています。

## 必要人数とシフトを編集する

必要人数の一括設定は、管理者メニューの「必要人数の設定」→「区分ごとに一括設定」から開きます。期間、区分、区分ごとの時間帯・人数を入力し、対象日を確認して保存します。時間帯は複数追加できます。

- 休日：土日と日本の祝日。土曜を含めず日曜・祝日とする設定も選べます。
- 祝前日：休日ではない、休日の前日。
- 平日：それ以外。
- 登録・更新：同じ日付・時間帯があれば人数を更新し、他の時間帯は残します。
- すべて置き換える：選択した区分に該当する日の必要人数を、入力した時間帯に置き換えます。

祝日判定には [JPHoliday](https://github.com/Lalcs/jpholiday) を使用します。祝日の公式情報は [内閣府](https://www8.cao.go.jp/chosei/shukujitsu/gaiyou.html) で公開されています。先の年の判定は現行ルールに基づくため、臨時の祝日変更があればライブラリの更新が必要です。

シフトの編集・削除は、シフト作成カレンダーで日付を選び「この日の登録済みシフト」から操作します。編集保存したシフトの作成方法は「手動」になります。

シフトの追加・編集時に、ヘルプ先などのメモ（500文字まで）と表示色を設定できます。メモは従業員の確定シフト一覧、希望カレンダーの選択日の確定シフト、店長の全体シフト表に表示されます。表示色は青・緑・オレンジ・紫・ピンク・グレーから選べます。「標準」の色は手動が青、自動生成が紫です。メモと色は後から変更・解除できます。

管理メニューの「全体シフト」では、店舗全員の登録済みシフトを「従業員×日付」の月間表で確認できます。スタッフごとの勤務日数・登録時間の合計と、日別の出勤人数も表示します。同じ人が同日に複数の時間帯で勤務する場合、出勤人数は1人として数えます。シフトがある人は、現在の所属が無効・未設定でも表示します。

表の日付からその日のシフト作成カレンダーを開き、勤務時間からシフト編集画面を開けます。「表示する月」で年・月を選ぶと自動でその月の表に切り替わります。前月・翌月のボタンでも移動できます。スマホでは氏名列を固定し、日付部分を横スクロールして確認できます。全体シフトは店長の管理画面で閲覧します。
